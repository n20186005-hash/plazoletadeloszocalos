## Check after Google discovers the URLs

1. Inspect each canonical URL in Search Console and confirm **Indexed**; request indexing only if appropriate. Deployment alone does not guarantee indexing.
2. At approximately 14 and 28 days **after indexing**, export the same Search type, country/device segmentation and equal-length comparison periods. Keep URL and query filters identical for fair comparisons.
3. Record impressions, clicks, CTR and average position separately for each new URL and its main query; segment by locale, device and country.
4. Interpret CTR alongside position and search intent. An apparent improvement from very few impressions is not yet strong evidence; changes in ranking or query mix can alter CTR.
5. Do not claim an observed uplift until fresh GSC data exists.

Photo assets already published on the site must be retained; homepage layout and original images remain unchanged.
